## 这个项目是什么

学生会的行政工作只有五件事，现在分别靠邮件、群聊、Excel、口头交代和老人的记忆完成。这个工作台把五步收进一处：

| 模块 | 一句话 |
|---|---|
| 收件台 | 校内通知汇到一处，筛成"今天该办什么" |
| 对标库 | 兄弟高校同类活动怎么做的，随时可查 |
| 筹备台 | 一场活动从立项到复盘的倒排期 |
| 资料问答 | 章程、报销、场地流程，问一句答一句，带原文 |
| 方案体检 | 定稿前先知道这类活动会死在哪 |
| 交接 | 换届不断档 |

**边界**：只做汇集、筛选、留痕三件事，不做全自动办公。任何一条结论都必须能点回原文。

## 关键结论（已实测）

**公众号采集走"关注 → 本地库 → 渲染正文"这条路线，不依赖任何第三方接口：**

1. 工作号关注兄弟高校公众号，文章自动落入本地微信库
2. 从 `biz_message` 库取标题与链接，带完整 `__biz`／`mid`／`idx`／`sn` 参数
3. 裸 HTTP 抓 `mp.weixin.qq.com` **已失效**（返回 JS 外壳，无正文）
4. 无头浏览器渲染可取到标题、正文、公众号名

实测样本：66 个公众号、1120 条消息、885 篇含链接文章。

**硬约束**：系统不会自动发现未知公众号，关注清单必须人工维护。
